#  格式说明
#  ─────────
#   · 每个游戏用 [代号] 开头一节，下面每行一个 key=value
#   · 空行、以 # 开头的注释行会被忽略
#   · 字段（未填写的会使用默认值）：
#
#       title       显示名（详情页大标题）
#       short       侧栏/卡片短名（不填则用 title 冒号前部分）
#       icon        卡片 / 侧栏图标 URL
#       cover1      详情页预览位 1（图片或视频：png/jpg/webp/gif/mp4/webm）
#       cover2      详情页预览位 2（不填则用 icon）
#       cover3      详情页预览位 3（不填则用 icon）
#       process     注入目标进程名（runmode=dll 时使用）
#       runmode     exe = 下载后直接运行 / dll = 下载后注入进程
#       download    下载直链
#                   .exe / .dll  → 直接下载到 C:\ProgramData\STARLINE
#                   压缩包       → 下载到同目录后静默解压，再按 runmode 挑文件
#       dev         开发商
#       pub         发行商
#       rel         发行日期（任意文本）
#       genres      类型，逗号分隔
#       features    特性，逗号分隔
#       featured    是否进首页 banner 精选轮播：true / false（不填 = false）
#                   · 只有 true 的游戏会进 banner，顺序沿用本文件顺序
#                   · 一个都没标（或标了的代号不存在）时，banner 自动回退成全部游戏
#       price30     30 天档显示价（USD），如 14.99
#       price90     90 天档显示价（USD）
#       priceLife   永久档显示价（USD）
#                   · 卡片和 banner 上显示的是这三档里最低的那个价格
#                   · 三档都留空则显示默认价 $19.99
#                   · 值可写 14.99 / $14.99 / 14,99，三种写法都认
#                   · 别名：price30 = price_30 = d30
#                          price90 = price_90 = d90
#                          priceLife = price_life = pricelt = life = price
#
#   · 新增游戏：复制一节，改代号和字段即可，无需重新编译
# ═══════════════════════════════════════════════════════════════════════════
